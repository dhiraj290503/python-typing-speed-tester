# ⌨️ Python Typing Speed Tester

A simple command-line **Typing Speed Tester** built using Python. This project randomly selects a sentence, measures the time taken to type it, calculates the **Words Per Minute (WPM)**, and checks the typing **accuracy**.

---

## 🚀 Features

- 🎲 Random sentence selection
- ⏱️ Measures typing time
- ⚡ Calculates Words Per Minute (WPM)
- 🎯 Calculates typing accuracy
- 🐍 Built using core Python concepts
- 💻 Beginner-friendly project

---

## 🛠️ Technologies Used

- Python 3
- `time` module
- `random` module

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/python-typing-speed-tester.git
```

2. Open the project folder

```bash
cd python-typing-speed-tester
```

3. Run the program

```bash
python main.py
```
